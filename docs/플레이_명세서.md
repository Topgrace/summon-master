### 설계 목표

아이는 마법학교 신입생으로 0의 주문서를 받는다. 사과 한 개로 봉인술과 소환술을 배운 뒤, 직접 들 수 없는 호박 한 개를 봉인해 용에게 운반한다. 숫자 문제를 맞히는 대신, **마법을 쓰기 위해 무엇이 몇 개 봉인되어 있는지 살펴보는 경험**을 설계한다.

## 조작 명세

*03 / INPUT — 물건을 힘으로 드는 행동과 마법으로 봉인하는 행동을 구분한다.*

### 3.1 봉인술: 물건에서 주문서로

실물을 누른 채 주문서까지 끌고 놓는다. 손가락을 따라가는 것은 반투명한 **마법 윤곽**이며, 실물은 원래 자리에 남는다. 주문서 위에서 놓으면 주문서의 빛이 실물을 끌어들인다. 무거운 호박에도 사과와 정확히 같은 입력 규칙을 적용한다.

### 3.2 소환술: 주문서에서 마법진으로

봉인된 주문서를 끌어 마법진 위에 놓는다. 주문서가 펼쳐지고 대상이 복원된다. 주문서는 소모되지 않고 아래 고정 위치로 돌아온다. 첫 버전의 소환은 봉인된 내용을 모두 꺼내며, 부분 소환 선택창은 없다.

| 입력 | 동작·판정 |
| --- | --- |
| 드래그 시작 | 기준 좌표에서 12px 이동부터 드래그로 판정한다. 길게 누르기나 별도 주문 버튼은 요구하지 않는다. |
| 놓기 성공 | 포인터가 넓힌 주문서/마법진 입력 영역 안에 있을 때 실행한다. 영역 바깥 24px까지 보정한다. |
| 놓기 실패·취소 | 윤곽·주문서가 원위치로 돌아간다. 물건 위치와 숫자는 변경하지 않는다. |
| 물건 짧게 누르기 | 대상을 살짝 강조한다. 첫 실전의 무거움 연출은 S06에서 한 번만 자동 재생하므로 다시 반복하지 않는다. |
| 주문서 짧게 누르기 | 현재 상태를 읽는다. 0: “지금은 비어 있어.” / 1: “사과 한 개가 봉인되어 있어.” 등. |
| 이동 표식 누르기 | **확정(D06)**: 조건을 만족하면 주인공이 목적지 쪽으로 짧게 걸어간 뒤 다음 장면으로 전환된다. 순간이동으로 표현하지 않는다. 경로 탐색·수동 걷기 조작은 없다. |
| 진행 중 재입력 | 봉인·소환 중 대상 입력과 이동을 잠근다. 일시정지·음소거는 허용한다. |

### 3.3 입력 접근성과 기본 허용 범위

주문서는 기준 화면에서 240×220px, 마법진은 220×150px 이상으로 제안한다. 일반 버튼의 입력 영역은 72×72px 이상으로 잡는다. 이 수치는 법규·연구 기준이 아니라 이번 시제품의 조정 가능한 시작값이다. 터치와 마우스 모두 누름·이동·놓기의 동일 결과를 가져야 한다.

> 주인공이 호박을 직접 들어 주문서 위로 옮기는 애니메이션은 금지한다. 사용자의 드래그는 마법 경로를 지정하는 것이며, 실제 운반은 주문서의 힘으로 일어난다.

## 화면·연출·안내 시스템

*04 / PRESENTATION — 마법의 감각은 살리되, 물건과 숫자의 연결을 가리지 않는다.*

### 4.1 기본 화면

| 영역 | 표현 |
| --- | --- |
| 상단 15% | 현재 장소·짧은 목표, 도움·음소거·일시정지. 숫자 점수나 마력 게이지는 표시하지 않는다. |
| 중앙 60% | 주인공·선생님·실물·소환 위치. 담기 전과 꺼낸 뒤 상태를 가리지 않는다. |
| 하단 25% | 고정 주문서 자리. 펼쳐진 주문서 일부는 중앙 영역까지 확장할 수 있다. |
| 대사 | 현재 화자 표시와 최대 두 줄의 짧은 문장. 자막은 기본 표시, 음성은 사용자 첫 입력 뒤 재생한다. |

### 4.2 주문서와 마법 연출

중앙 숫자는 가장 큰 정보로 배치하고, 숫자 뒤에는 밝은 여백을 두어 배경그림과 겹쳐도 읽히게 한다. 배경 사물의 윤곽은 종류를 알아볼 수 있을 만큼 남긴다. 봉인은 바깥에서 종이 안으로, 소환은 종이 안에서 바깥으로 빛이 이동한다. 획득 팝업이 숫자 변화를 덮지 않게 한다.

| 연출 | v0.1 제안값 |
| --- | --- |
| 봉인 / 소환 | 각 1.2초 / 1.4초. 마지막 0.2초 구간에서 물건 위치·배경·숫자를 동기 갱신한다. |
| 무거움 / 가벼움 | 호박을 못 드는 동작 1.8초, 봉인 후 한 손으로 주문서를 드는 동작 1.2초. |
| 호박 복원 | 원래 크기로 복원되어 받침 위에 놓이는 효과음. 받침만 살짝 반응하고 전체 화면은 흔들지 않는다. |
| 연출 감소 설정 | 이동·반짝임을 짧은 전환으로 줄인다. 물건의 이전/이후 위치와 숫자 변화는 유지한다. |

### 4.3 안내 단계

**확정(D04):** 첫 수업은 직접 안내하고, 독립 실습·실전은 자율 시도 후 대상 강조→짧은 말 힌트→손 모양 시범 순으로 도움을 준다. 아래 8·16·24초는 확정값이 아닌 검토용 기본값이며, 시제품 사용 후 조정한다.

S02·S03은 처음부터 설명과 손 모양 시범을 제공한다. S04·S07·S09는 정답을 먼저 말하지 않는다. 조작 가능한 상태에서 진행이 없을 때 8초에 H1 대상 강조, 16초에 H2 짧은 힌트, 24초에 H3 손 모양 경로를 제안값으로 적용한다. 자동 수행은 하지 않는다.

유효한 조작 진행 시 타이머를 새로 시작한다. 대사·연출·일시정지·창 비활성 중에는 시간을 세지 않는다. 도움 버튼은 즉시 다음 단계의 힌트를 보여준다. 사소한 오조작은 장면 상태를 바꾸지 않으며, 안내 수준은 관찰 기록에 남긴다.

## 입학과 0의 주문서

*06 / SCENE DETAIL A — S00–S01 / 이야기와 조작의 시작을 구분한다.*

### S00. 마법학교에 도착하다

**시작 상태:** 시작 화면에는 제목과 큰 시작 버튼만 있다. 플레이어에게 주문서는 아직 지급되지 않았다. 아동 이름·계정 입력은 요구하지 않는다.

**연출:** 시작을 누르면 교문이 열리고 주인공이 교실로 향한다. 복도에서는 선배가 화분 한 개를 봉인해 가볍게 가져가는 짧은 장면을 보여준다. 화분은 비조작 배경 소품이며, 플레이어의 주문서나 대상 목록에는 포함되지 않는다.

> 선생님: “어서 오렴. 오늘부터 너도 마법학교의 학생이야.”
> 선생님: “첫 수업에 필요한 건, 바로 이 주문서란다.”

**아이의 행동:** 시작 버튼을 누른 뒤 도입을 본다. 도입 넘기기는 교실의 S01로만 이동하며, 실습을 완료 처리하지 않는다.  
**완료 조건:** 교실 작업대, 사과 한 개, 아직 접힌 주문서가 화면에 놓인다.  
**관찰 포인트:** 이 단계에서는 숫자 이해나 조작 성공을 평가하지 않는다.

### S01. 빈 주문서를 펼치다

**시작 상태:** 작업대에는 사과 한 개, 접힌 주문서 한 장이 있다.  
**아이의 행동:** 강조된 주문서를 누르면 펼쳐진다.  
**화면 변화:** 배경그림이 없는 0 주문서가 나타나고 중앙 0이 한 번 은은하게 강조된다.

> 선생님: “아직 아무것도 봉인하지 않아서 0이라고 적혀 있구나.”
> 선생님: “이 사과로 첫 마법을 배워 보자.”

**진행 조건:** 주문서 펼치기와 대사 종료 후 S02로 진행한다. 처음의 0은 빈 상태 설명이며, 마법 등급이나 능력 부족으로 표현하지 않는다.  
**도움:** 주문서를 누르지 않으면 S01에서는 주문서의 펼침 부분만 강조한다. 아직 봉인 드래그 안내는 시작하지 않는다.  
**체크포인트:** CP01 = S02 시작, 사과는 작업대, 주문서는 EMPTY.

> 읽기가 어려운 아이에게도 같은 정보가 전달되도록 음성·그림을 함께 제공한다. “봉인술”이라는 단어를 읽거나 따라 말해야 진행되는 조건은 두지 않는다.

## 봉인술과 소환술 배우기

*07 / SCENE DETAIL B — S02–S03 / 안내를 따라 동일한 물건을 왕복시킨다.*

### S02. 봉인술 안내

**시작 상태:** 사과 한 개가 작업대에 있고 주문서는 0이다. 소환 마법진은 아직 나타나지 않는다.  
**안내:** 봉인술 이름을 짧게 표시하고, 손 모양이 사과에서 주문서로 이동하는 시범을 한 번 보여준다.

> 선생님: “봉인술은 물건을 주문서 안에 담는 마법이야.”
> 선생님: “사과를 주문서 위로 옮겨 보렴.”

**아이의 행동:** 사과의 마법 윤곽을 주문서까지 끌고 놓는다.  
**연출:** 빛이 사과를 감싸 종이 안으로 끌어들인다. 완료 시 작업대의 사과를 숨기고, 사과 배경과 큰 1을 표시한다.  
**피드백:** 빈 작업대와 달라진 주문서를 한 화면에 유지한다.

> 선생님: “봉인 성공! 사과 하나가 주문서 안에 들어갔어.”

**진행·복구:** 봉인 완료 후 CP02를 저장하고 S03으로 넘어간다. 잘못 놓거나 취소하면 CP01 상태를 그대로 유지한다. 안내가 자동으로 대신 봉인하지 않는다.

### S03. 소환술 안내

**시작 상태:** 사과는 봉인되어 있고 주문서는 1이다. 작업대 오른쪽에 소환 마법진이 나타난다.  
**아이의 행동:** 주문서를 마법진으로 끌어 놓는다.

> 선생님: “이번에는 소환술이야. 봉인한 사과를 불러내 보자.”
> 선생님: “주문서를 마법진 위로 옮겨 보렴.”

**연출:** 사과 그림에서 빛이 빠져나와 같은 사과 한 개로 복원된다. 완료 순간 사과 배경이 지워지고 1 → 0으로 바뀐다. 주문서는 원래 위치로 돌아온다.  
**피드백:** 사과 실물과 0 주문서를 나란히 보여준다.

> 선생님: “사과가 돌아왔어. 주문서는 다시 비었구나.”

**진행·복구:** 소환 완료 후 CP03을 저장하고 S04로 진행한다. 잘못된 위치에 놓으면 주문서만 되돌아오며 봉인된 사과와 1은 유지된다.

## 독립 실습과 첫 심부름

*08 / SCENE DETAIL C — S04–S05 / 안내를 따라 한 것과 스스로 사용한 것을 나누어 기록한다.*

### S04. 혼자 두 마법을 사용하다

**시작 상태:** 사과 한 개는 작업대, 주문서는 0. 소환 마법진은 보인다. 손 모양 안내는 처음부터 표시하지 않는다.

> 선생님: “이제 네 힘으로 해보렴. 사과를 봉인했다가 다시 불러내는 거야.”

**아이의 행동:** 사과를 봉인하고 다시 소환한다.  
**진행 상태:** PRACTICE_SEAL → PRACTICE_SUMMON → PRACTICE_DONE의 순서다. 첫 봉인이 끝나면 CP04, 다시 소환하면 CP05를 저장한다.  
**완료 조건:** 두 동작이 실제 입력으로 차례로 완료되고 사과는 작업대, 주문서는 0이어야 한다.

**도움:** 04절의 H1–H3을 적용한다. 도움을 받았더라도 진행은 허용하되, 관찰 결과를 “완전 자율”과 구분한다. 빈 주문서를 마법진에 놓으면 “지금은 봉인된 물건이 없어.”라고 알려주고 상태를 유지한다.  
**중복 입력 방지:** 마지막 소환 완료 즉시 장면 전환 대사 중에는 물건 입력을 잠근다. 다음 장으로 사과를 다시 봉인해 가져가는 경로는 열지 않는다.

### S05. 자신의 주문서와 첫 심부름

**시작 상태:** 독립 실습이 끝났고 주문서는 0이다. 사과는 교실 작업대에 남아 있다.  
**연출:** 선생님이 이 주문서를 주인공에게 정식으로 맡긴다. 창밖 온실에는 작은 용과 빈 접시가 보인다.

> 선생님: “이제 이 주문서는 네 것이란다.”
> 선생님: “온실의 용에게 간식을 가져다주겠니?”
> 선생님: “준비실에 있는 호박 하나를 가져가면 된단다.”

**아이의 행동:** 준비실 방향의 이동 표식을 누른다. 주인공이 빈 주문서를 챙겨 이동한다.  
**안내 원칙:** 이 대사에서는 “봉인해서 가져가라”는 해결법을 먼저 말하지 않는다. 할 일과 목적지만 전달한다.  
**진행 조건:** 준비실 도착 시 S06. 주문서 상태는 EMPTY 유지.  
**자산 범위:** 창밖 용은 온실 장면 자산을 축소 재사용한다. 별도 퀘스트 게시판·가방 관리 화면은 만들지 않는다.

> 교실의 사과를 전달하는 이전 아이디어는 이 흐름에 섞지 않는다. 첫 실전의 대상은 반드시 무거운 호박 한 개다.

## 너무 무거운 용의 간식

*09 / SCENE DETAIL D — S06–S07 / 배운 마법을 떠올릴 이유와 기회를 함께 만든다.*

### S06. 직접 들 수 없는 호박

**시작 상태:** 준비실 바닥에 주인공의 몸통만 한 호박 한 개가 있다. 주문서는 0이다.  
**연출 제안:** 입장 직후 주인공이 호박을 안고 들어보려는 1.8초 내외의 짧은 자동 연출을 한 번 재생한다. 호박은 거의 움직이지 않는다. 상해·낙하·겁주는 실패는 없다.

> 주인공: “으으… 너무 무거워.”

**진행 조건:** 연출 직후 S07로 넘겨 조작을 허용한다. 실패 횟수·특정 탭·정답 대답을 요구하지 않는다. 연출 감소 설정에서는 들기 전/실패 후 포즈와 대사로 대체한다.  
**체크포인트:** CP06 = 무거움 체험 완료, 호박 바깥, 주문서 0. 다시 열어도 같은 실패 연출을 강제로 반복하지 않는다.

### S07. 봉인술로 해결하기

**시작 상태:** 호박은 바닥, 주문서는 0. 목표는 “온실에 간식 가져가기”이며 처음에는 주문 이름을 지시하지 않는다.  
**아이의 행동:** 호박의 마법 윤곽을 주문서로 끌어 놓는다. 교실에서 배운 것과 같은 입력이다.  
**연출:** 주문서에서 뻗은 빛이 무거운 호박을 끌어들인다. 실제 호박은 주인공의 팔로 들리지 않는다. 바닥의 호박이 사라지고 호박 배경·1이 나타난다.

> 주인공: “어? 가볍다!”

**가벼움 표현:** 주인공이 주문서를 한 손으로 들어보고 가볍게 걸을 자세를 취한다. 숫자는 계속 1이며, 무게 수치나 등급 표시를 추가하지 않는다.  
**진행 조건:** 봉인 완료 후 CP07 저장. S08 시작에서 가벼움 연출을 마치면 온실 이동 표식을 활성화한다.

## 운반·소환·전달 완료

*10 / SCENE DETAIL E — S08–S10 / 가벼운 종이가 다시 무거운 실물이 된다.*

### S08. 주문서로 운반하기

**시작 상태:** 호박은 봉인되어 있고 주문서에는 호박 배경·1이 표시된다. S07에서 이어지는 가벼움 확인 연출을 먼저 마친다.  
**아이의 행동:** 온실 이동 표식을 누른다. 주인공은 주문서를 가볍게 들고 지정 경로를 따라 걷는다.  
**연출:** 준비실에서의 무거움과 대비되는 가벼운 보행. 하단 주문서 상태는 이동 중에도 계속 보인다. 복도는 짧은 전환 배경이며 자유 탐험 공간이 아니다.  
**완료 조건:** 온실 도착 후 CP08 저장, S09로 진행. 이동으로 주문서 내용이 비워지거나 복제되어서는 안 된다.

### S09. 용의 접시에 소환하기

**시작 상태:** 용 옆의 크고 튼튼한 접시에 마법진이 보인다. 주문서는 호박 배경·1이다.  
**아이의 행동:** 주문서를 접시 마법진으로 끌어 놓는다. 주문 이름·손 시범은 처음부터 노출하지 않는다.  
**연출:** 빛이 종이 밖으로 빠져나와 원래 크기의 호박으로 복원된다. 접시에 놓일 때 낮고 짧은 “쿵” 효과와 받침 반응을 준다. 용 위나 공중에 떨어뜨리지 않는다.  
**상태 변화:** 호박은 접시, 주문서는 배경 없음·0. 완료 후 CP09를 저장한다.

**도움:** 8초에 접시 영역 강조, 16초에 “간식을 접시에 놓아줄까?”, 24초에 주문서→접시 손 모양 경로를 제공한다.  
**예외:** 용이나 바닥에 놓으면 주문서가 제자리로 돌아가고 호박 배경·1을 유지한다. 접시 외의 영역에는 소환되지 않는다.

### S10. 첫 실전 완료

**시작 상태:** 호박이 접시 위에 있고 주문서는 0.  
**연출:** 용이 호박을 끌어안고 간식을 먹기 시작한다. 첫 시제품은 완전히 먹어 없애는 수량 변화까지 구현하지 않고, 호박이 전달된 최종 장면에서 마무리한다.  
**입력:** 물건을 다시 봉인하는 입력은 종료 장면에서 잠근다. 다시 하기·종료만 제공한다.

> 선생님: “혼자 들 수 없는 물건도 가져왔구나.”
> 선생님: “봉인해서 옮기고, 필요한 곳에서 소환하면 되는 거야.”

**완료 기록:** S02·S03·S04·S07·S09의 수행 여부와 도움 수준을 보관한다. 도입을 넘겨도 실습은 면제되지 않는다. 다시 하기는 전체 상태와 관찰 세션을 새로 시작하며, 기존 관찰 기록은 세션 번호로 구분하며, 아이에게 별도 저장 선택을 요구하지 않는다.

### 11.2 반드시 지킬 불변 조건

각 대상은 WORLD 또는 SEALED 중 한 곳에만 있다. 화면을 떠난 교실의 사과도 데이터상 교실에 남는다. scroll_content와 봉인된 대상 ID·종류·개수는 일치해야 한다. 봉인·소환 완료 시 물건 위치·배경·숫자를 한 번에 확정하고 체크포인트를 기록한다.

연출 중에는 기존 안정 상태와 실행 예정 동작을 분리한다. 입력을 잠근 채 연출을 끝내고 한 번만 확정한다. 취소·새로고침·오류로 중단되면 마지막 완료 체크포인트로 되돌리며, 물건 삭제만 처리되거나 중복 생성된 중간 상태를 남기지 않는다.

## 사용 관찰과 완료 기준

*13 / PLAYTEST — 조작 습득·마법의 활용·수량 해석을 별개로 관찰한다.*

### 13.1 관찰 절차 제안

제작자의 기능 검수 후, 대상 수준의 아동 3–5명 정도로 소규모 탐색 관찰을 제안한다. 이는 설계 결함을 찾기 위한 시작 규모이며 학습효과를 입증하는 표본 기준이 아니다. 보호자 동의를 받고, 아이가 중단하려 하면 즉시 종료한다. 녹음·촬영은 기본 사용하지 않는다.

진행자는 아이의 손을 대신 움직이지 않고 게임의 안내 수준을 먼저 관찰한다. 외부에서 직접 조작법을 알려줬다면 그 사실을 별도 표시한다. 질문은 장면을 멈추는 시험이 아니라, 행동만으로 알기 어려운 경우에 짧게 덧붙인다.

| 관찰 지점 | 유도하지 않는 확인 | 기록 |
| --- | --- | --- |
| S02 봉인 후 | “사과는 지금 어디에 있을까?” | 주문서/바깥/없어짐/판단 어려움 |
| S03 소환 전 | “이 주문서를 쓰면 어떻게 될까?” | 물건 복원 예상 여부 |
| S04 독립 실습 | 말로 답하게 하기보다 수행 관찰 | 봉인·소환 각각 H0/H1/H2/H3/외부 도움 |
| S07 무거운 호박 | 기본 목표만 제시하고 첫 행동 관찰 | 마법 시도/물건 누르기 반복/대기 및 도움 수준 |
| 사과1·호박1 비교 | 완료 후 두 기록을 보여주며 “왜 둘 다 1일까?” | 개수 언급/크기·무게 해석/판단 어려움 |
| S09 소환 후 | “주문서 안에는 지금 뭐가 있을까?” | 비어 있음 이해 여부 |

### 13.2 기록 항목

익명 세션 번호, 장면 ID, 첫 유효 행동, 취소·실패 횟수, 도달 도움 단계, 외부 도움, 상태 설명, 중단 원인을 기록한다. 반응시간은 참고값이며 빨리 한 아이를 더 높은 수준으로 평가하지 않는다. 앱 기록을 넣는 경우 개발 모드의 로컬 기록만 사용하고 외부로 자동 전송하지 않는다.

### 13.3 수정·완료 판단

물건이 복제되었다고 이해하거나, 호박 봉인 조작을 직접 들기와 구별하지 못하거나, 마법진 위치를 반복해서 찾지 못하면 원인을 분리해 조작·연출을 수정한다. 기능 오류가 없고 관찰에서 발견된 주요 혼동을 정리·수정한 뒤, 스토리 담당자가 해당 범위의 플레이 흐름을 검토한다.

> “튜토리얼을 끝냈다”, “마법을 스스로 활용했다”, “0과 1의 수량 의미를 설명했다”는 서로 다른 결과다. 하나의 성공 여부나 학습효과 점수로 합치지 않는다.

**확정(D07):** 임시 캐릭터와 단순한 배경으로 S00–S10 전체 플레이를 구현하고, 조작과 흐름을 확인한 다음 최종 그림을 적용한다.

단순한 도형·임시 캐릭터여도 실제 드래그, 취소, 상태 변화, 지정 위치 소환, 장면 이동, 힌트, 체크포인트가 작동해야 한다. 봉인·소환의 방향성과 무거움·가벼움 대비는 초기부터 확인한다.

### 14.2 뒤로 미룰 것

최종 캐릭터 원화, 상세 배경, 긴 입학 영상, 전문 성우, 복잡한 카메라 연출, 추가 소품과 장비 시스템은 기본 동작 검토 후 진행한다. 장식 마법 문양에는 숫자 2–9를 넣지 않아 첫 범위의 숫자 초점을 흐리지 않는다.

### 15.3 다음 산출물의 범위

첫 와이어프레임은 홈·설정 화면이 아니라 ① 사과 봉인 전/중/후, ② 사과 소환 전/중/후, ③ 호박 들기 실패/봉인/가벼운 운반, ④ 접시 소환/주문서 0을 대상으로 한다. 명세와 화면 검토 후 별도 구현 계획을 검토하고 코드를 작성한다.
