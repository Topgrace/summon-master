### 1.1 S03 후속 보완 — T013

- 사용자 요청에 따라 교실 소환술 배우기를 소환 전·중·후 3컷으로 추가했다. 위 표는 보완 전 초안의 검토 기록으로 유지한다.
- 플레이 명세 S03에 선생님 대사·순차 탭 손 시범·작업대 마법진·주문서 1→0의 전후 화면 기준을 추가했다.
- 개정본의 B–D는 S03 안내 수업이고, G는 호박의 실전 소환 S09이다. 소환 중에는 주문서를 한 장만 표시하며, 소환 후에는 사과 실물 한 개와 빈 주문서 0을 함께 표시한다.
- S03 추가 당시에는 선택 취소(P09) 등 미정 동작을 승인한 것으로 취급하지 않았다. P09는 이후 별도 사용자 승인으로 확정했으며 4절에 기록한다. 다른 장면의 상세 전/중/후 화면과 실제 사용성 검증은 별도 작업으로 남긴다.
- 개정본 A–G를 직접 확인했다. B·C의 사과 배경을 교정한 뒤 B의 봉인 상태, C의 주문서 한 장, D의 실물 사과 한 개·빈 주문서 0과 대사를 확인했다. 실제 조작·연출 검증은 미실행이다.

### 3.1 P02 화면·입력·연출 시작값 — 스마트폰 기준 재검토

스마트폰 가로 우선·태블릿/PC 지원은 확정했다. 아래 수치는 기존 태블릿 기준에서 제안한 값으로, 스마트폰에서 그대로 적용할 값으로 승인되지 않았다. 화면·입력 크기는 스마트폰 가로의 실제 표시 영역을 기준으로 재검토하며, 연출·힌트 시간도 결정 대기다.

| 항목 | 기존 제안·현재 검토 상태 | 명세 근거 |
| --- | --- | --- |
| 설계 화면 | 기존 1280×720·16:9 설계안의 적용 방식 재검토. 실제 스마트폰 해상도 제한 아님 | 1.2절·D01 |
| 화면 배분 | 기존 상단 15% / 중앙 60% / 하단 25%. 스마트폰 가로에서 재검토 | 4.1절 |
| 주문서·마법진 입력 영역 | 기존 주문서 240×220px / 마법진 최소 220×150px. 실제 표시 크기에서 재검토 | 3.3절 |
| 일반 버튼 입력 영역 | 기존 최소 72×72px. 스마트폰에서의 최소 터치 크기는 별도 검토 | 3.3절 |

| 무거움·가벼움 연출 | 들기 실패 1.8초 / 가벼운 주문서 들기 1.2초 | 4.2절. 들기 실패의 자동 재생 여부는 P03에서 별도 결정 |

- px는 기존 1280×720 설계 좌표의 값이며 스마트폰에 표시되는 실제 픽셀 크기를 뜻하지 않는다. 최소 지원 화면, 화면 비율별 맞춤·기기 여백, 글자·숫자·터치 영역의 표시 크기와 입력 좌표 변환은 P02·T005에서 구체화하고 Q18로 확인한다.
- 기존 제안에서 하단 25%는 높이 180px이고 주문서 높이는 220px이다. 중앙 영역 확장을 허용한 기존 배치만으로 스마트폰 배치가 검증된 것은 아니며, 작은 가로 화면에서도 대상·숫자·자막을 가리지 않는지 확인한다.
- 사과·호박의 실제 탭 영역과 경계 보정은 명세에 수치가 없다. T005에서 배치와 함께 제안·검토한다. 이전 드래그 판정 수치는 적용하지 않는다.
- 현재 확정된 것은 기기 우선순위다. P02의 수정 시작값은 검토 후 별도 확인하며, P03의 무거움 체험 방식 및 P04–P08의 대사·설정·종료·음성 제작·기록 정책도 별도 결정이다.
- 검증 범위: 명세의 기존 수치·승인 상태 대조. 실제 화면 배치, 기기별 입력 크기, 애니메이션·힌트 체감은 아직 검증하지 않았다.

## 4. 두 번 탭의 세부 조작 — P09, 확정

2026-09-28 사용자 답변 “확정”으로 승인했다. 확정 동작의 기준은 [플레이 명세서](플레이_명세서.md) 3.4절이며, 아래는 결정 요약이다.

- 첫 주문서 탭: 선택한 주문서 테두리를 강조하고 현재 내용의 짧은 음성·자막을 제공한다. 독립 실습·실전에서는 선택만으로 정답 대상을 함께 강조하지 않는다. 상태 안내가 다음 탭을 막지 않으며 새 안내가 시작되면 이전 음성은 중단한다.
- 선택 취소: 선택한 주문서를 다시 탭하거나 빈 배경을 탭하면 해제한다. 물건 위치·숫자는 유지한다.
- 잘못된 대상: 선택은 유지하고 짧게 상태를 알린다. 빈 주문서 선택 후 마법진을 누르면 명세의 “지금은 봉인된 물건이 없어.”를 사용한다. 올바른 대상으로 다시 탭할 수 있다.
- 마법 완료·장면 전환·체크포인트 복원: 선택을 해제하고 다음 동작은 다시 주문서 선택부터 시작한다. 선택 대기 자체는 새 체크포인트로 저장하지 않는다.
- 일시정지: 선택을 포함한 현재 진행 상태를 유지해 재개한다. 창 비활성도 같은 원칙을 적용하며 대사·연출·이동·힌트 타이머는 정지한다.

반영 범위: 플레이 명세 v0.3의 3절, 11절, Q02·Q03·Q05·Q12·Q13·Q15·Q16, 14절 조작 안내 자산, 15.2절 D02. P02–P08은 결정 대기이며, 실제 앱 동작 검증은 미실행이다.
